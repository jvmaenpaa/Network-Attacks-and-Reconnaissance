# x) rtl_433

  To be able to use rtl_433 on your Linux VM you need to first install tools, library's and files that enable you to download the rtl_433, enable your device to send and receive data over USB. This is done with the command `sudo apt-get -y install atool wget libssl-dev libtool libusb-1.0-0-dev librtlsdr-dev rtl-sdr libsoapysdr-dev`. 
  Then you need to download the zip file from github that contains the copy of rtl_433, `wget https://github.com/merbanan/rtl_433/releases/download/25.02/rtl_433-soapysdr-openssl3-Linux-amd64-25.02.zip`. And then the zip file must be extracted `aunpack rtl*.zip`. After these three commands you can test if you can run the rtl_433 with the following command, `./rtl_433`.
  The output (if everything went accordingly) should look like this.
